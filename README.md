# AuraLumia

Die neue Hauptseite für Jennifer Kindereits Somatic-Karma-Welt: Archetype Navigator, Transit Orakel, Tarot, Audio Bundle, Somatic Karma Code und der Podcast **Karma mit Zimt & Zucker**.

## Lokal starten

```bash
pnpm install
pnpm dev
```

## Produktions-Build

```bash
pnpm build
```

Die Seite ist statisch exportierbar und für Vercel konfiguriert.
